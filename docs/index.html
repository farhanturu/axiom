Installation

1

Clone Repository

git clone https://github.com/farhanturu/axiom.git
2

Setup Environment

cd axiom && python3 -m venv .venv && source .venv/bin/activate
3

Install Dependencies

pip install -r requirements.txt

Usage

Discovery

Identify CDN, WAF, and origin IPs

python3 main.py -t https://target.com --discover

WAF Bypass

Test WAF evasion techniques

python3 main.py -t https://target.com --bypass waf --param id

Port Scan

Scan open ports with service detection

python3 main.py -t https://target.com --scan ports

Full Assessment

Run all modules at once

python3 main.py -t https://target.com --full

API Reference

Client

HTTP client with TLS fingerprinting

from core.client import AxiomClient client = AxiomClient(fingerprint='chrome') resp = client.get('https://target.com') client.close()

Fingerprint

Browser fingerprint generation

from core.fingerprint import FingerprintGenerator fg = FingerprintGenerator() ua = fg.user_agent('chrome') headers = fg.headers()

WAF Bypass

Test WAF evasion payloads

from modules.bypass.waf import WAFBypass waf = WAFBypass(client) results = waf.test_sqli(url, param='id')
