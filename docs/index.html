Install

1

Clone

git clone https://github.com/farhanturu/axiom.git
2

Setup

cd axiom && python3 -m venv .venv && source .venv/bin/activate
3

Install

pip install -r requirements.txt

Commands

Discovery

python3 main.py -t URL --discover

Cari CDN, WAF, Origin IP

WAF Bypass

python3 main.py -t URL --bypass waf

Test bypass WAF

Port Scan

python3 main.py -t URL --scan ports

Scan port terbuka

Full Scan

python3 main.py -t URL --full

Jalankan semua modul
